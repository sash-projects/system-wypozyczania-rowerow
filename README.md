VELOCYCLE – System Wypożyczania Rowerów

Opis projektu

VELOCYCLE to system umożliwiający zarządzanie wypożyczaniem rowerów miejskich.
Projekt został przygotowany w celu przedstawienia analizy i projektu systemu informatycznego wspierającego proces rezerwacji, wypożyczania oraz serwisowania rowerów.

System umożliwia:

* rejestrację i logowanie użytkowników,
* przeglądanie dostępnych rowerów,
* filtrowanie i wyszukiwanie rowerów,
* rezerwację rowerów,
* zarządzanie wypożyczeniami,
* zgłaszanie usterek,
* obsługę zgłoszeń serwisowych,
* zarządzanie flotą rowerów.

Aktorzy systemu

Klient niezalogowany

* rejestracja konta,
* logowanie do systemu,
* przeglądanie rowerów.

Klient zalogowany

* rezerwacja roweru,
* anulowanie rezerwacji,
* przegląd własnych rezerwacji,
* zgłaszanie usterek,
* edycja profilu.

Pracownik

* zarządzanie rezerwacjami,
* zarządzanie flotą,
* przegląd zgłoszeń,
* zmiana statusów rowerów,
* historia wypożyczeń.

Mistrz serwisowy

* przyjmowanie zleceń,
* naprawa rowerów,
* zamykanie zgłoszeń serwisowych.
